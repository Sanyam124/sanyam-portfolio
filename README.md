## 🚀 Getting Started Locally

### Prerequisites

- Node.js (v18.17.0 or later)
- npm or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sanyam124/sanyam-portfolio.git
   cd sanyam-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

### Production Build

```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel (1-Click)

1. Push this repository to your GitHub: `https://github.com/Sanyam124/sanyam-portfolio`.
2. Go to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import `sanyam-portfolio` from your GitHub.
4. Click **"Deploy"**. Vercel will automatically build and deploy your site in ~30 seconds with automatic SSL and continuous deployment!
